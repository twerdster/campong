Choose a control

Move the pointer on the court to control the left paddle. The right paddle follows the ball. Touch works too.

For camera mode, keep the scene still, save an empty background, then move a hand inside each teal stripe. Each stripe controls its corresponding paddle.

Pointer mode. Camera is off.
New code by Aaron Wetzler with agent assistance (2026), inspired by Rom Herschkovitz and Nofar Carmeli's project. Camera frames stay in this page. This uses simple background subtraction and a foreground-row median, not the original Android/OpenCV implementation. No projector, latency or tracking-accuracy validation is claimed.
