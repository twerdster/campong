# Source recovery status

## Folder supplied on 2026-11-15

Rom Herschkovitz supplied a historical source folder while noting that he did not know whether it was the latest version or whether it worked. The archive inventory contains 541 files, including generated output, dependencies and local configuration. The application's Java source consists of two classes, `MainActivity` and `XMLparser`, both read during inspection. The application label in `strings.xml` is `3DV1`. `MainActivity` implements camera capture, projected Gray-code decoding, optical-distortion correction and 3D reconstruction. No Pong game engine, ball or paddle implementation was identified in the supplied application source.

Of the 147 files outside generated build output, IDE/cache directories and operating-system metadata, 42 resource, configuration and script files exactly match files already archived in the separate [Android 3D scanner repository](https://github.com/twerdster/android-3d-scanner). The two application Java classes are not exact matches. That correspondence does not establish the supplied folder's complete version history, authorship or relationship to CamPong.

The supplied archive has been retained privately for follow-up. Its code, binaries, local configuration files and shared-folder access link have not been published in this repository. No supplied binary or script was executed. A build or port of that application would not demonstrate that CamPong works, so no such result is claimed. The CamPong application source remains unrecovered.
